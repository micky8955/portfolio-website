# Portfolio Website

This is my personal portfolio website showcasing my skills, projects, and resume.

## Features

- Modern dark theme design
- Responsive layout that works on all devices
- Interactive navigation with smooth scrolling
- Project showcase section
- Contact form
- Resume download functionality
- Professional layout with clean typography

## Technologies Used

- HTML5
- CSS3 (with custom properties)
- Vanilla JavaScript
- Font Awesome for icons

## Sections

- Hero section with introduction
- About Me section
- Education background
- Skills showcase with icons
- Projects gallery
- Experience section
- Contact information
- Footer with social links

## Setup

To run this project locally:

1. Clone the repository
2. Open `index.html` in your browser

No additional setup required!

The website is hosted using GitHub Pages and can be viewed at: [https://micky8955.github.io/portfolio-website/](https://micky8955.github.io/portfolio-website/)
